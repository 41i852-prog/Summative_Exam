My Growing Pain

One thing I struggled with most during coding was grid and CSS tags because I am not familiar with the function of different tags or what tags can I use. For example, I always do the unexpected wrong styling and it took a long time on figuring out the error and fix it. In addition, for the grid setup, I was confused about its function, purpose, convenience, and how to make the coding process simpler and clearer. When my code didn’t work, I usually check the code on website to see which variable or which parts went wrong. And try to test different way of writing code, like use padding instead of margin when I want to move the text in a section to avoid the weird gap between different sections.Wireframing felt easier than coding because coding include styling and construct structure with raw code and not a visualized and customized tool of doing wireframing.One thing I learned about myself while learning to code is that I like the process of thinking the logic of code, but I don’t really motivated to write the actual code.

My response

After several practice with grid, table, and CSS tags, I can finally write code individually without internet. This time, I use AI for helping me review and summarize all the command and trick that I need to know, which saved a lot of time and it's useful. I think the growing pain really help for learning better, if I didn't fight until 3 a.m. last night, it's impossible to make a website that's actually works. Therefore, I am being thankful for my previous self for not giving up when I almost fell asleep on the table in front of the computer.
